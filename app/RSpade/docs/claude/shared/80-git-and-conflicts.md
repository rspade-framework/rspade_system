## GIT DISCIPLINE

**Commits = MAJOR MILESTONES, and only when the user requests one.** Individual changes are not commits. **The sole exception**: checkpoint commits between reviewed implementation agents during a delegation epic (the delegation fragment).

## MANDATE: RESOLVING MERGE CONFLICTS

**A merge conflict is a code-review task, not a cleanup chore.** Both sides are work someone intended to keep; discarding a side is a deliberate, justified decision — never a default, never a batch operation. **LOAD SKILL `rspade:merge-conflicts` before resolving one** (the required per-hunk procedure: enumerate, learn the other side's intent with `git log -p`, keep both by default, escalate rather than guess, verify, report what was kept and dropped).

**FORBIDDEN unless the user explicitly directs it for that specific conflict:** `git checkout --ours/--theirs <path>`, `git merge -X ours/theirs` or `git checkout HEAD -- <dir>` over a conflict set you have not read hunk by hunk; resolving by file *category* ("just build artifacts / generated files / machine churn" — **category is a hypothesis, verify it per file**); `git stash` or `git reset --hard` to make a conflict "go away". A blanket resolution that looks like tidying silently reverts intended work, with no error to show for it.

## CLASS OVERRIDES

To customize a framework PHP class without modifying `system/`, declare a class of the SAME SIMPLE NAME in `rsx/`: the manifest SHADOWS the framework file and the old FQCN resolves to yours everywhere, bundles included (`rsx:overrides:list` lists what is in force). **Only PHP classes are overridable**: an `rsx/` JS class or jqhtml component named like a framework one FAILS the manifest build - change browser behaviour through a published extension point (`Button_Utils.set_loader()`, `Rsx.set_default_spinner()`, a subclass under your own name); **a stylesheet is never an override** (compiled alongside, the cascade decides). **A core MODEL is EXTENDED, never copied**: `class X_Model extends X_Model_Abstract` declaring only what it changes (a copy is REFUSED at manifest build; a non-`#[Replaceable]` method calls `parent::`); when your copy of a framework table is site-scoped, `use Site_Scoped` supplies the tenant boundary — never a hand-rolled scope. **Every OTHER framework class is copy-and-replace**, frozen while the original keeps moving: `CLASS-OVERRIDE-DRIFT-01` (`rsx:check`, HIGH) and the `rsx:health` "Class Override Drift" row name every member your copy lacks. **A SEAM (`Staff_Authorizable`, `Portal_Authorizable`, `fetch()`, `#[OnEvent]`) beats an override whenever the addition is policy.** Details: `rsx:man class_override`, `rsx:man rsx_git`.
