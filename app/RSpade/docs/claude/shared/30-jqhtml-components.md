## JQHTML COMPONENTS

A component is up to three co-located files sharing one name - `Foo.jqhtml` (markup; `<Define:Foo>` IS the root element, not a wrapper), optional `Foo.js` (lifecycle, logic, state), `Foo.scss` (its whole look) - found by the manifest with no registration, invoked as `<Foo $arg=value>` or `$(sel).component('Foo', {...})`. **Comments in `.jqhtml` are ALWAYS `<%-- --%>`** - never `<!-- -->` (still parsed for jqhtml constructs, JS inside executes, it ships to the DOM; `JQHTML-COMMENT-01`) and never bare `//` in markup.

**Three state buckets, never mixed**: `this.args` (in; read-only in `on_load()`), `this.data` (load results, the source of truth for display; writable ONLY in `on_create()`/`on_load()`, frozen otherwise), `this.state` (UI state, writable anywhere). **Hooks**: `on_create()` -> `on_render()` -> `on_load()` (DOM, `this.state` and `this.args` writes THROW here) -> `on_loaded()` -> `on_ready()` -> `on_stop()` (cleanup; runs for every jQuery or framework removal); `on_attach()`/`on_detach()` only for work that pauses off-page. **Ajax belongs in `on_load()`** - independent calls under one `Promise.all`, sequenced only when a later call's ARGUMENTS come from an earlier RESULT; never refetch from a handler. `reload()` restores `this.data` to its `on_create()` snapshot and re-runs `on_load()`; `render()`/`redraw()` re-run the template only.

**A component with `on_load()` is CACHED** (a revisit paints the last `this.data` instantly, then revalidates) and loses that SILENTLY unless its args are keyable or it defines `cache_id()` (else `data-nocache` + a console warning). **A parent's re-render destroys and rebuilds its children** (instance, `this.state`, handlers): bind namespaced and idempotent (`.off('click.ns').on('click.ns', ...)`), never behind a one-shot `this._wired` flag. **Never re-render a component from its own `on_ready()`** (it loops and never reaches ready) **nor await one in `on_loaded()`** (a hang). **Every wait outside `on_load()` goes through `this.alive()`** (`await this.alive(Controller.save(...))`).

**A LIVE STREAM (terminal, log tail, chat) is the Standalone tier**, written like a jQuery plugin: no `on_load()`, a static template, `on_ready()` is its `$(document).ready()`, changes by `.append()`/`.hide()`, state in `this.state`, and it is never `reload()`ed or re-rendered by a parent. **A view template past ~325 lines is split into page-private REGION components** (skill `rspade:view-decomposition`).

Skill `rspade:jqhtml` (syntax, the hook-by-job matrix, `$sid`/`this.sid()`/events, "Designing for the cache", the Standalone tier's worked example). `rsx:man jqhtml`.
