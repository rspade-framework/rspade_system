## STANDARD LIBRARY & TIME

**Never reimplement a shipped utility** - debounce, type checks, deep comparison, HTML escaping, dot-path array access, byte/duration formatting, reflection. JS: `is_*`/`isset`/`empty`, `escape_html()` / `sanitize_rich_text_html()` / `nl2brhtml()` / `html_to_text()` (never `$('<div>').html(x).text()`), `foreach` `clone` `coalesce` `hash` `deep_equal`, `rwlock`; PHP: `response_*()`, `array_get`/`array_set`/`array_merge_deep`, `Arr::first()`, `bytes_to_human()`, `random_hash()`, `rsxrealpath()`; `Manifest::php_*`/`js_*` reflection; `Rsx_Storage` (non-critical data only), `Rsx.url_hash_*`; **`$(input).rsx_numeric()` is the ONE numeric filter**; QR codes are `Rsx_Qr_Code::generate()`; **an amount of money is `Rsx_Money`, never a float** (skill `rspade:money`). Skill `rspade:rsx-stdlib`.

**ALL debounce logic is the core `debounce(fn, 250)`** - never a hand-rolled `setTimeout`/`clearTimeout` pair or an in-flight/"run again" flag; 250 ms unless a compelling, stated reason says otherwise.

**The third-party tier is guaranteed present - never install a duplicate or hand-roll one**: libphonenumber (PHP + JS), `phpspreadsheet`, **`league/csv` for ALL CSV**, **`league/commonmark` for markdown** (`Markdown_Rendition::render()`), htmlpurifier, guzzle, and headless Chromium via `playwright` **in BOTH container images, production included, because applications generate PDFs with it** - never strip it, never add a second browser or a PDF package. **pcntl is CLI-ONLY.** `rsx:man standard_library`.

**IP geolocation is `Rsx_Geo_Ip::lookup($ip)` / `label($ip)`** (DB-IP City + ASN Lite, downloaded and refreshed by the framework; country alpha-3, `org` from the default-deny `rsx.geo_ip.networks` list of ASNs and CIDR ranges): call it whenever a location is shown and **NEVER store the answer as data** - no column, JSON field, history row or cached payload; a message composed for a person (email, SMS, PDF) may print the location resolved when it is composed - (null until a database is acquired and once one is six months past its release, changes as it updates), never a security control, and every screen or message showing one carries the DB-IP credit (`<Geo_Ip_Credit />` on a screen). Skill `rspade:geo-ip`.

**Dates are `Rsx_Time` (moments) and `Rsx_Date` (calendar dates)** - identical API in PHP and JS, THROWING on the wrong type, and **ISO strings everywhere, never Carbon**. **Model attributes are ALREADY STRINGS** - never `->format()` one; `$casts` `'date'`/`'datetime'`/`'timestamp'` is blocked by `rsx:check`, and a rendered datetime goes through `Rsx_Time::format_timestamp()` & co., never raw interpolation (`JQHTML-DATETIME-01`). **A timezone belongs to the PERSON (`login_users.timezone`, NULL = automatic), never to `users`, and only the person sets it**; the display zone resolves per request, so never append a zone suffix by hand. Skill `rspade:date-time`.

**A value users RECORD is an instant, a calendar date, or an intended day with an optional time** - per-day totals read the DAY column, never a date derived from a timestamp. Skill `rspade:time-value-design`.
