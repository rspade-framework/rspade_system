## MODELS & ORM

**MANDATE: load skill `rspade:models` before modifying any model or writing any migration, and ask of EVERY new column whether it is a declared kind** (enum, text type, type-ref pair, money, `never_export`, derived). **Columns are declared in ONE property**, `public static $columns = ['col' => [...]]` (keys `enum`/`text_type`/`type_ref`/`money`/`never_export`/`revision_exclude`/`derived`+`from`; a child's entry REPLACES the parent's; **enums** are BIGINT, `Project_Model::STATUS_ACTIVE`, `$project->status_id__label`, never VARCHAR/ENUM), read only through its accessors (`enum_values('col')`, `derived_columns()`, ...; `::$columns` is `MODEL-COLUMNS-02`); a malformed entry or a `$enums`/`$text_types`/`$type_ref_columns`/`$neverExport`/`$revision_exclude` property is `MODEL-COLUMNS-01`, build FATAL.

**NEVER mass-assign** (`fill()`/`create($request->all())` THROW `MassAssignmentException`) - assign every field explicitly. **NEVER eager load** - `->with()`/`withCount()` THROW; load what you need, when you need it. **A secret column is `never_export`** (`MODEL-NEVER-EXPORT-01`) - Laravel's `$hidden` is not a security control. **A computed value JS needs is an APPENDED property, `$appends` + an accessor delegating to its method** - never a key hand-added inside `fetch()`. **Column length is `Model::field_length('col')` / `Model.field_length('col')`** - never a restated schema number. **Bulk `->update()`/`->delete()` runs each row through `save()`/`delete()` on a model with side effects; `->raw_bulk()` and `DB::table()` fire NOTHING** (follow one with `$record->realtime_emit()` / `Realtime::bulk_changed()`). Skill `rspade:models`; `rsx:man model`.

**A site-scoped write needs the site's WRITE LOCK** (`#[Writer]`, `Site_Lock::write()`); raw `DB::table()` / `->raw_bulk()` writes are not caught. **`#[Site_Lock_Exempt('<reason>')]`** is for append-only view/audit/telemetry tables only (one call site: `Site_Lock::write_exception()`) - never business data, nor a table read to decide business data.

**DERIVED COLUMNS** (`['derived' => 'method', 'from' => [...]]`) are STORED, computed by the model on save, and **never assigned** (save, `Form_Edit::set()`, bulk `update()` THROW "is a derived column"; `MODEL-DERIVED-01`). **No cross-record trigger**: the model whose change moves another record's value calls its `rederive()` (a `save()` override). "Editable unless a rule supplies it" is TWO columns, source + derived. `rsx:man derived_columns`.

**Model fetch** - JS reaches records through ONE framework endpoint per model, opt-in: `await Project_Model.fetch(id)` / `fetch_or_null()`, lazy relationships `await project.client()`. `#[Ajax_Endpoint_Model_Fetch]` + MANDATORY `#[Auth]`, record-level rules in the `fetch()` body, a denial answers "not found". **`fetch()` is for SECURITY, never aliasing or formatting; changing it requires user approval; a separate controller endpoint fetching one record is an anti-pattern; a model missing from the JS bundle means STOP and ask.** Skill `rspade:model-fetch`.

**Declared TEXT types**: `'col' => ['text_type' => Rich_Text::class]` makes a TEXT column a value object (`Rsx_Text_Abstract`), filtered on every write, travelling as a `{__TEXT, raw, empty}` envelope. **A bare string assigned to it is PLAIN TEXT** (escaped) - so code composing markup RETURNS THE TYPE (`Type::from_untrusted_encoded()`), never a string, the one silent mistake; **test emptiness with `is_empty()`, never `=== ''`**; side effects go in the type's `after_model_saved()`. Skill `rspade:text-types`.

**MONEY**: `'col' => ['money' => true]` on a DECIMAL(p,2) column (p <= 18, `MODEL-MONEY-01`; every DECIMAL/FLOAT/DOUBLE column is declared money or `[]`, `MODEL-DECIMAL-01`) reads as an **`Rsx_Money` object (PHP and JS), NEVER a float or number** - methods only (`add()`, `compare()`, `equals()`, `is_zero()`), "has one" is `!== null`. **The two silent mistakes: truthiness or an operator (`==`, `<`, `===`, `if ($m)`) on the object (`MODEL-MONEY-02`), and a float handed in** ("carries floating-point residue"). An endpoint reads input with `Model::money_from_submitted('col', $value)`, an `is_input_problem()` refusal is a field error ("at most two decimal places", "is larger than this field can hold"); **rounding is always named** (`ROUND_HALF_UP`), every step range-checked ("outside the range the system can hold"); SQL totals are `sum_money('col')`. Skill `rspade:money`; `rsx:man money`.

**Fact groups**: one fact edited as one thing but stored in several columns (a date-or-datetime "when", a type/id pair) is declared in `public static $fact_groups` - **undeclared, a stale `Form_Edit` save overwrites the other editor's change silently**.

**Revision history** is `public static $revisions = true;` (one transaction per unit of work; an import declares one per record with `Revision::unit_of_work()`; `REVISION-01` is a build FATAL; **`Revision::transaction_id()` MINTS a transaction** - call it only to store the id). **There is no restore and no automatic activity text; both are the application's job.** Skill `rspade:revisions`.

**Detail tables** (class-table inheritance, `$detail_tables`, `$party->party_person->first_name`) throw on wrong-type access. Skill `rspade:detail-tables`.
