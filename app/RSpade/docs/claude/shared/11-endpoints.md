## ENDPOINTS

**Ajax endpoints are browser-only.** A `#[Ajax_Endpoint]` static method on a controller is callable from JS under the controller's own name - no route, no URL, no wiring: `await My_Controller.save({name: 'Test'})`. **`$.ajax()` to a local URL THROWS.** **Every Ajax response is HTTP 200**: the `{_success, _ajax_return_value}` envelope carries the outcome, failures are `response_error(Ajax::ERROR_*, $message)`, and unhandled errors already log and surface to the user, so catch only what you handle. **The exception: an infrastructure outage** (rsx-lockd or the database gone) fails the WHOLE request as a 500 on every channel - no fallback, never caught or named by app code (`rsx:man error_handling`). Skill `rspade:ajax-error-handling` (the codes, the `rsx:ajax` CLI).

**The external API** is `#[Api_Endpoint]` + `#[Api_Param]` on a `Rsx_Api_Controller_Abstract`: `/api/vN/` paths, GET/POST only, `Authorization: Bearer rsx_...` only, running as the key's owner (site scope automatic - never hand-write `where('site_id')`). A key may be narrowed by path-pattern scopes (403 `insufficient_scope`; `Api_Scopes::validate()` / `matches()` are the ONE validator and matcher, never a JS twin) or minted read-only (403 `read_only_key`); **`API-GET-PURE-01`** (manifest FATAL) keeps a GET handler side-effect-free - GET reads, POST writes, never both. **There is no privileged CLI channel into the API**: a script mints its own key (`rsx:api:key:create` / `key:temp`, `--user=` required) and calls `/api/vN` over HTTP. Skill `rspade:external-api`.

**SITE LOCKS - every request holds its site's lock.** Ajax, API and companion endpoints are READERS by default; **one that writes declares `#[Writer]`**: the site's write lock and one transaction, committed when it RETURNS (a returned `response_form_error()` included - validate before writing), rolled back when it THROWS (`throw new Rollback_Response(<the error you would return>)` answers it AND rolls back). **The serialization is a CONTRACT**: inside a writer or `Site_Lock::write()` nothing else changes the site, so read-then-write needs no re-check or private lock. A reader that saves a site-scoped model FATALS (`Site lock enforcement: ... without site N's write lock`); **there is no read-to-write upgrade**, so code that reads then writes is a writer from its start - except a view/audit/telemetry record, which stays a reader under `Site_Lock::write_exception()`. **A write lock stops every other user on the site, so writing code is ENGINEERED to be minimally invasive**: `#[Writer]` covers ONE discrete operation; anything more is `#[Manual_Lock]` with a short `Site_Lock::write()` section per discrete operation (atomic only where the business rule demands, each re-reading, a status marker valid between them); never across a call to another system; read, release, THEN transmit (`Site_Lock::held_mode()`); a long write lock only for a critically atomic operation, made fast or split into reversible steps (HOLDING A LOCK WELL). `#[Manual_Lock]` = no automatic lock (also signing in through `RsxAuth::enter_site()`). Page routes take none unless `#[Reader]`/`#[Writer]`; `init()`/`pre_dispatch()` run unlocked; both are still enforced. The attributes go only on Ajax, API, route and companion surfaces (`SITE-LOCK-01`); `rsx:site_lock:endpoints` lists every mode. **An endpoint returns right away: work that grows with the tenant's data is a task** (validate, `Task::dispatch()`, return the handle; the UI follows it with `Rsx_Task.watch()`) - **an export reads one keyset page per read section**, and **a mass edit, import or reassignment releases the write lock between items** (or blocks / chunked statements), collects its errors and reports them at the end, **after a dry run when it matters**. Skill `rspade:site-locks`.

**External API bodies are JSON OBJECTS** - never null, a list or a 204 (`['items' => ...]`, `['result' => 'success']`) - and every body and Ajax envelope carries `_duration_ms` / `_completed_at` (the one exception: a standard-shaped document such as an OpenAPI root, answered `Rsx_Api::document()`). **`_request_ref`** names a writer request so a retry replays (`_replayed: true`; 409 `request_ref_reused`, 410 `request_response_expired`); `Rsx_Form` sends one on every submission, and a button's writer call gets one from `Ajax.action()` - plain `Ajax.call()` sends none. `rsx:man request_history`.

**Proxority** fair-queues every PHP request in the RSpade container; a surface steers it with at most ONE of `#[Unthrottled]` / `#[Priority]` / `#[Media]` - misplaced is `PROXORITY-01`, a manifest FATAL; inert outside the container. `rsx:man proxority`.
