## FORMS AND MODALS

**One engine, in framework core** - `<Rsx_Form $controller $method [$data]>`, `<Form_Errors />`, `Form_Input_Abstract` - which an application never copies; `Form_Field` (label, asterisk, help) is the APPLICATION's field chrome. **The tag is the ONLY place an endpoint is named, and `form.submit()` the only submission path** (a `type="submit"` button and Enter are auto-wired); `$data` present = edit, absent = create, values bind by `$name`.

**Validation lives on the SERVER, once - no client-side required/format/length checks anywhere**: a client check that duplicates a server rule MASKS its absence, which then surfaces only when a script or API caller hits the endpoint. `$required` is only an asterisk; an input's `_validate()` is the one exception (a state the server cannot be told). **Blank is a value; absent means untouched**: a blank field arrives as `''` and must validate - **"keep the old value when blank" is forbidden**. Errors are `response_form_error($message, ['title' => 'Required'])`.

**A form that edits a record saves through `Form_Edit::run($record, $params, fn (Form_Edit $edit) => $edit->set('field', $value))`** - changed fields only, under a row lock, asking when a concurrent save changed the same field; the model declares `$revisions = true`, the `$data` seed carries `updated_at`, and you never wrap it in your own `DB::transaction()`. **An endpoint may answer with a QUESTION** (`response_form_question($key, $question)`, read back with `Form_Questions::answer($params, $key)` - null = not asked; **validate -> ask -> write**); the app registers ONE `Rsx_Form.set_question_handler()` from `on_app_modules_define()`, and `Rsx_Form.CANCELLED` is not the answer "No".

**Every form places exactly one `<Form_Errors />`** (without one it throws when it must show a failure). **`$name` goes on the INPUT, never on `Form_Field`, and you NEVER set `$value`**; `$max_length` is REQUIRED on `Text_Input` (`Model.field_length('col')`, a number, or `-1`). **An input implements `_get_value()`/`_set_value()` - NEVER `val()`** - and uses `_mark_ready()`, `_notify_input()`, `_focus()` (skill `rspade:form-input-contract`). `form.dirty()` / `'dirty'` is "unsaved changes". **An edit page or dialog stays hidden until loaded** (`@spinner_until_ready('always')` / `spinner_until_ready: 'always'`); values that arrive after it is shown use `form.populate(promise)`, and `submit()` refuses while loading.

**A modal is CHROME around a form**: `const result = await Modal.form({title: 'Edit Client', component: 'Client_Edit_Form', component_args: {id}});` drives the `<Rsx_Form>` inside and resolves with the result, or `false` on cancel. **In `Modal.show({buttons})`, only a literal `false` from a button callback keeps the dialog open - `null` CLOSES it** and discards what the user entered. **Load app skill `modals` before writing ANY dialog** - it has the full worked example, the `default: true`/Enter rule and the positional basic dialogs.

Skill `rspade:form-engine`, app skill `form-components`. `rsx:man form_conventions`, `rsx:man form_input`, `rsx:man modals`.
