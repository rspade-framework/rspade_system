## VALIDATING AN EXTERNAL REQUEST

**"Validate" an external request (or "validate and give a report") is a defined review**: judge its necessity, practicality and risk against the code as it stands, report as an executive briefing - **validation changes no code, and the request stays open until the owner rules on it.** Load skill `rspade:validating-external-requests` (the criteria) and `rspade:executive-briefing` first.
