## THE FRAMEWORK'S OWN APPLICATION (`Sys/`)

`system/app/RSpade/Sys/` (the `/_sys` control panel + the `/apidocs` console) is an ordinary RSX application shipped inside the framework and scanned like `rsx/` - **not a runtime special case: a framework feature awkward to use here is a framework defect, never a `Sys/` exemption.** Isolation is the single leading `_` on every class, component and `@rsx_id` declared there (`NAME-RESERVED-01`; the same name in `rsx/` would be read as a class override) plus bundles shared in NEITHER direction: a `Sys/` bundle names no `rsx/` path or app class (`CONV-BUNDLE-04`, it ships its own theme), and an `rsx/` bundle names nothing under `Sys/` (`CONV-BUNDLE-02`). It is reached from app bundles only through `config('rsx.always_published_routes')`. Modified only on an `IS_FRAMEWORK_DEVELOPER=true` tree; gate `is_sysadmin` (`#[Replaceable]`), switch `rsx.sys_panel.enabled`. Deep docs: `Sys/CLAUDE.md`, `Sys/app/{sys,apidocs}/CLAUDE.md`; skill `rspade:sys-panel`; tests `--group=sys_panel`.
