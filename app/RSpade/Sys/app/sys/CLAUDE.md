# app/RSpade/Sys/app/sys - the control panel module

The `/_sys` control panel: one SPA bootstrap controller, one route controller, one
layout, and one directory per screen. Namespace is `App\RSpade\Sys\App\Sys` for
the PHP files at this level; a screen directory's PHP (its controller, its grid) is
`App\RSpade\Sys\App\Sys\<Dir>` (`tasks/` -> `...\Tasks`).

| File | What it is |
|---|---|
| `_Sys_Bundle.php` | the panel's only bundle. Includes `jquery`, `lodash`, `_Sys_Theme_Bundle`, `app/RSpade/Sys/theme`, `app/RSpade/Sys/lib`, `__DIR__`. Names no `rsx/` path and no app class (`CONV-BUNDLE-04`). |
| `_Sys_Spa_Controller.php` | `#[SPA] index()` -> `rsx_view(SPA, ['bundle' => '_Sys_Bundle'])`. Extends `_Sys_Endpoint_Controller_Abstract`, whose inherited `pre_dispatch()` enforces `rsx.sys_panel.enabled` for every SPA screen. |
| `_Sys_Controller.php` | the panel's server-rendered route: `GET /_sys/logout` -> `RsxAuth::logout()` + redirect to `/`. Same inherited refusal. |
| `_Sys_Impersonation_Controller.php` | `GET /_sys/stop-impersonating` (`stop()`), the way back from the Users screen's "Sign in as this user". THE ONE PANEL SURFACE NOT GATED `is_sysadmin`: class-level `#[Auth('is_logged_in')]` (while impersonating the effective identity is never a developer, and a method gate cannot widen `_Sys_Controller`'s class gate, hence its own controller). Body: not impersonating -> redirect `/`; impersonator not `is_developer` -> `response_unauthorized()`, impersonation left running; else `Session::stop_impersonation()`, restore + forget the site stored under `RETURN_SITE_KEY` (`'sys.impersonation.return_site'`, `Session::put_value()`), redirect to `_Sys_User_View_Action` of the impersonated id. GET like `/logout`: it only ends a privilege. Published into every bundle (`rsx.always_published_routes`) so the application's banner can `Rsx.Route()` it. `Sys_Panel_Gate_Test` names it as the single exception. Same inherited refusal. |
| `_Sys_Layout.{jqhtml,js,scss}` | the persistent chrome: a full-height sidebar column (sticky contents; below 768px an off-canvas drawer behind the top bar's menu button, closed by the backdrop, Escape or a navigation - `set_nav_open()`), top bar with the page title (`document.title` is `System - <title>`), the action's page actions and the sign-out link, `<main $sid="content">`. `on_create()` builds the nav and filters it through `Permission.can_access()`; `on_action()` re-marks the active item, repaints the title and refills the top bar from the action's optional `page_actions()` (an HTML string or element, may be async; handlers bind on `Spa.layout.$sid('page_actions')`, namespaced, and unbind in `on_stop()`). |
| `_Sys_Error_Screens.js` | registers `_Sys_Unauthorized` / `_Sys_Not_Found` / `_Sys_Error` with `Error_Screens.set_components()`, so a denied gate, an unclaimed URL or a failed action inside the panel renders the panel's own body. |

`dashboard/`, `debug_flags/`, `tasks/`, `email/`, `logs/`, `sites/`, `users/` -
each `_Sys_<Name>_Action.js` + `.jqhtml`, composing
`<_Sys_Page_Scaffold><Slot:main>...</Slot:main></_Sys_Page_Scaffold>`.

An app whose `Main::init()` declares its staff site every request overrides the chosen site on the next request, and signs the whole session out when the identity has no active membership there - the dialog says so; `rsx:man sys_panel` IMPERSONATION). The health report runs INSIDE a web request here, where `rsx:health` runs it under
the CLI. A check that reads its own process therefore describes the WEB tier (the
php-fpm SAPI, its user, its extensions); `Environment_Health_Checks::cli_tier_rows()`
is the one check that knows it, answering INFO for the CLI extension tier outside
the CLI SAPI. The `Web Exposure` and `Ignition Read-Only` rows fetch this site's own
`APP_URL` over HTTP with no timeout, which a web request can only do while the pool
serving page requests has a free worker.

## Rules that bite here

- Every class, component and `@rsx_id` starts with exactly ONE underscore
  (`NAME-RESERVED-01`); directories never do.
- Filenames under `app/RSpade` are case-exact matches of the class they declare.
- `#[Auth('is_sysadmin')]` / `@auth('is_sysadmin')` on every surface - a surface with no
  gate does not deploy.
- Every controller here extends `App\RSpade\Sys\Lib\_Sys_Endpoint_Controller_Abstract`
  (the enabled switch) and declares `#[Auth('is_sysadmin')]` at class level - save
  `_Sys_Impersonation_Controller` (`is_logged_in`, the single named exception); a
  screen's Ajax endpoints (a grid's `datagrid_fetch` included) live on its own
  controller in the screen's directory. `Sys_Panel_Gate_Test` enumerates them.
- URLs come from `Rsx.Route()` / `Rsx::Route()`; the layout's sign-out link is
  `Rsx.Route('_Sys_Controller::logout')`.
